# s9ss profile

Dark, ink-on-paper profile README. Banner, badge row, three sections, a quote, a contribution chart.

```
github-profile/
├── README.md
├── tools/
│   └── make-contribution.ps1
└── assets/
    ├── banner.svg        wifi sticker over the name plate
    ├── wifi.svg          the sticker on its own
    ├── rule.svg          section divider
    ├── brain.svg         Know About Me art
    ├── laptop.svg        Top Projects art
    └── contribution.svg  generated chart
```

Every sticker is hand-written SVG: black shapes, a white die-cut border, a halftone dot pattern over the fill. No raster files, nothing fetched at runtime.

## editing

- Fonts are system stacks. SVG inside an `<img>` cannot load webfonts, so the name is Segoe UI / Inter bold with wide tracking, and the chart labels fall back to Consolas.
- Name: one `<text>` in `banner.svg`. Change the string, then match the accent rule length underneath.
- Wifi sticker: same geometry in `wifi.svg` and inlined at the top of `banner.svg` — three arcs plus a dot, each drawn twice (wide white stroke for the die-cut, black stroke for the ink).
- Brain and laptop: shape, then white outline copy, then halftone `<pattern>` fill. Retint by changing `#0B0E13` (ink) and `#F2F5F9` (paper).
- `rule.svg` is a faded line plus one accent diamond; it stretches to any width.
- README art sizes: brain `190`, laptop `150`. Both sit right of the text via `<img align="right">`, with `<br clear="right" />` after the block.

## refreshing the chart

```
powershell -ExecutionPolicy Bypass -File tools/make-contribution.ps1
```

Reads the public contribution calendar for `s9ss`, groups the last twelve months, rewrites `assets/contribution.svg`. No token required. Run it monthly, commit the result.

## cache gotcha

`raw.githubusercontent` caches for a few minutes and ignores query strings, so a fresh push can keep serving old bytes for up to about five. The image paths carry `?v=2`. Bump that number on every edit so GitHub's own proxy re-resolves the file.
